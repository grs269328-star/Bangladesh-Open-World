# বাংলাদেশ ওপেন ওয়ার্ল্ড — Unity Starter

এটি একটি প্রাথমিক Unity C# স্টার্টার সোর্স প্রজেক্ট; সম্পূর্ণ গেম বা APK নয়।

## প্রস্তাবিত পরিবেশ
- Unity 2022.3 LTS অথবা Unity 6
- Android Build Support (Unity Hub)
- Android ফোনে পরীক্ষা

## শুরু করার ধাপ
1. কম্পিউটারে Unity Hub ও Unity Editor ইনস্টল করতে হবে।
2. নতুন 3D Core প্রজেক্ট তৈরি করে এই `Assets` ফোল্ডারটি প্রজেক্টে কপি করতে হবে।
3. দৃশ্যে একটি Plane, Capsule এবং Camera তৈরি করে স্ক্রিপ্টগুলো সংযুক্ত করতে হবে।
4. Android Build Support দিয়ে APK তৈরি ও ফোনে পরীক্ষা করতে হবে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- এখানে প্রকৃত 3D চরিত্র, গাড়ি, অ্যানিমেশন, সম্পূর্ণ গ্রাম-ম্যাপ বা অনলাইন সার্ভার নেই।
- মাল্টিপ্লেয়ার চালু করতে Netcode/Relay বা সার্ভার, নেটওয়ার্ক সেটআপ ও পরীক্ষা দরকার।
- এই ZIP সরাসরি APK নয় এবং GitHub-এ আপলোড করলেই APK তৈরি হবে না।
